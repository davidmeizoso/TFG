
## Objective
The goal of this project is to design and implement a system capable of evaluating cybersecurity risk in Small and Medium Enterprises (SMEs) using Machine Learning techniques.

The system aims to:
- Predict the level of cybersecurity risk
- Identify key risk factors
- Provide interpretable results using XAI techniques such as SHAP

## Technologies
- Python
- Scikit-learn
- Pandas / NumPy
- Jupyter Notebooks
- Explainable AI (SHAP)

## Data Sources
- MITRE CVE Database
- NVD (National Vulnerability Database)
